# Forward LED Chaser

A simple Arduino LED chaser project where **5 LEDs light up one after another from left to right**.

## Components

* Arduino UNO
* 5 LEDs
* 5 × 220Ω resistors
* Breadboard
* Jumper wires

## Pin Connections

| LED   | Arduino Pin |
| ----- | ----------- |
| LED 1 | D2          |
| LED 2 | D3          |
| LED 3 | D4          |
| LED 4 | D5          |
| LED 5 | D6          |

## How It Works

The program turns each LED ON one at a time, waits for a short delay, and then turns it OFF before moving to the next LED.
