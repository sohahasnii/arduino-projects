# Reverse LED Chaser

A simple Arduino LED chaser project where **5 LEDs light up one after another from right to left**.

## Components

* Arduino UNO
* 5 LEDs
* 5 × 220Ω resistors
* Breadboard
* Jumper wires

## Pin Connections

| LED   | Arduino Pin |
| ----- | ----------- |
| LED 1 | D2          |
| LED 2 | D3          |
| LED 3 | D4          |
| LED 4 | D5          |
| LED 5 | D6          |

## How It Works

The program starts with the LED connected to D6 and moves backward until it reaches the LED connected to D2.
