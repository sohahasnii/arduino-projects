# arduino-projects
A collection of basic Arduino projects and experiments created to learn and practice sensor interfacing, actuator control, PWM, displays, and fundamental Arduino programming.

These projects focus on understanding individual components and combining them into simple working circuits.

🎯 **Purpose**

This repository is for learning and practicing Arduino fundamentals through small hardware experiments.

The projects cover:
 Digital and analog I/O
 Sensor interfacing
 Reading sensor data
 PWM
 Motor control
 Servo control
 OLED displays
 Buzzer control
 Basic circuit connections
 Serial communication
